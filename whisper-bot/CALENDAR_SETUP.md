# 📅 Настройка Google Calendar интеграции

## Быстрый старт (без OAuth)

По умолчанию бот создает `.ics` файлы которые пользователь может открыть и добавить в любой календарь (Google, Apple, Outlook).

**Никакой настройки не требуется!** Просто установите зависимости:

```bash
pip install -r requirements.txt
```

---

## Расширенная настройка (OAuth для прямого создания событий)

Если хотите чтобы бот создавал события напрямую в Google Calendar пользователей:

### Шаг 1: Создание проекта в Google Cloud

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите **Google Calendar API**:
   - Перейдите в "APIs & Services" → "Enable APIs and Services"
   - Найдите "Google Calendar API"
   - Нажмите "Enable"

### Шаг 2: Настройка OAuth consent screen

1. Перейдите в "APIs & Services" → "OAuth consent screen"
2. Выберите "External" (для тестирования)
3. Заполните обязательные поля:
   - App name: "Whisper Bot"
   - User support email: ваш email
   - Developer contact: ваш email
4. Добавьте scopes:
   - `.../auth/calendar` (создание и редактирование событий)
5. Добавьте тестовых пользователей (email адреса)
6. Сохраните

### Шаг 3: Создание credentials

1. Перейдите в "APIs & Services" → "Credentials"
2. Нажмите "Create Credentials" → "OAuth client ID"
3. Выберите "Desktop app"
4. Название: "Whisper Bot Desktop"
5. Нажмите "Create"
6. Скачайте JSON файл
7. Переименуйте в `google_credentials.json`
8. Поместите в директорию `credentials/` проекта

### Шаг 4: Структура директорий

```
whisper-bot/
├── bot.py
├── calendar_parser.py
├── calendar_integration.py
├── credentials/
│   ├── google_credentials.json  # Скачанный файл
│   └── user_tokens/             # Создается автоматически
│       └── {user_id}_token.json # Токены пользователей
```

### Шаг 5: Первая авторизация

При первом использовании функции прямого создания событий:

1. Бот откроет браузер с запросом авторизации
2. Войдите в Google аккаунт
3. Разрешите доступ к календарю
4. Токен сохранится автоматически

**Важно:** На сервере OAuth flow не работает автоматически. Для production используйте:
- Service Account (для корпоративного использования)
- Или оставьте только .ics файлы (проще и безопаснее)

## Использование

### Создание события через .ics файл

1. Отправьте голосовое сообщение: *"Завтра в 14:00 встреча с командой на час"*
2. Нажмите "📆 Создать событие в календаре"
3. Бот отправит .ics файл
4. Откройте файл → событие добавится в ваш календарь

### Примеры голосовых команд

```
"Послезавтра в 10 утра созвон с Иваном"
"В пятницу в 15:30 встреча по проекту"
"23 ноября в 9:00 конференция"
"Завтра весь день выходной"
```

Бот автоматически извлекает:
- ✅ Дату и время
- ✅ Название события
- ✅ Место (если указано)
- ✅ Участников
- ✅ Описание

## Формат создаваемых событий

```.ics файл содержит:
- Название события
- Дата и время начала/окончания
- Описание
- Место проведения
- Участники
- Напоминание за 15 минут

Совместим с:
- ✅ Google Calendar
- ✅ Apple Calendar
- ✅ Outlook
- ✅ Любой календарь поддерживающий iCalendar

## Troubleshooting

### Бот не находит информацию о встрече

Убедитесь что в сообщении указаны:
- Дата (например: "завтра", "23 ноября", "в пятницу")
- Время (например: "в 14:00", "с 10 до 12")

### OAuth ошибка на сервере

OAuth flow требует браузер и не работает на headless сервере.

**Решение:**
1. Используйте только .ics файлы (рекомендуется)
2. Или настройте Service Account для production

### Модуль календаря недоступен

Установите зависимости:
```bash
pip install -r requirements.txt
```

## Отключение календаря

Если не нужна интеграция с календарем, просто не устанавливайте зависимости:
- `icalendar`
- `google-auth`
- `google-auth-oauthlib`
- `google-api-python-client`

Бот будет работать без функции календаря.

## Безопасность

⚠️ **Важно:**
- Файл `google_credentials.json` содержит секретные данные
- НЕ коммитьте его в git
- НЕ делитесь им публично
- Файлы `*_token.json` также секретные

Все эти файлы уже добавлены в `.gitignore`.

## Дополнительные возможности

### Изменение таймзоны

По умолчанию используется `Europe/Moscow`. Чтобы изменить:

```python
# В calendar_parser.py
def parse_datetime(date_str: str, time_str: str, timezone: str = "Europe/Moscow"):
```

Замените на вашу таймзону (например: "America/New_York", "Asia/Tokyo")

### Изменение напоминаний

По умолчанию напоминание за 15 минут. Чтобы изменить:

```python
# В calendar_integration.py, функция create_ics_file
alarm.add('trigger', '-PT15M')  # Измените 15M на нужное значение
```
