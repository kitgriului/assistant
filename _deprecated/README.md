# Устаревшие скрипты

Эта директория содержит утилиты и скрипты, которые использовались для разработки, тестирования и администрирования проекта GuardBot, но больше не являются частью основного кода для продакшена.

## ⚠️ Важно

**Файлы в этой папке:**
- Не предназначены для использования в продакшене
- Могут быть несовместимы с текущей версией БД
- Сохранены исключительно для исторических целей и возможного повторного использования логики

## 📁 Структура

### `/admin` - Административные утилиты
Скрипты для настройки пользователей, ролей и первоначальной конфигурации:

- `add_users_direct.py` - Прямое добавление пользователей в БД
- `create_admin.py` - Создание первого администратора
- `make_admin.py` - Назначение прав администратора пользователю
- `set_admin.py` - Альтернативная утилита назначения админа
- `init_users.py` - Инициализация таблицы пользователей
- `setup_users.py` - Пакетная настройка пользователей
- `create_new_request.py` - Создание тестовых заявок
- `add_indexes.py` - Добавление индексов в БД (уже применено)
- `migrate_db.py` - Миграция структуры БД (разовая операция)
- `quick_reset.py` - Быстрый сброс данных для разработки
- `reset_bot.py` - Полный сброс бота и БД

### `/diagnostics` - Диагностические инструменты
Скрипты для проверки корректности данных и отладки:

- `check_data.py` - Проверка целостности данных в БД
- `check_db.py` - Диагностика структуры БД
- `check_qr.py` - Проверка QR-кодов и их валидности
- `debug_approve.py` - Отладка процесса одобрения заявок
- `fix_webhook.py` - Исправление конфигурации вебхука
- `generate_test_qr.py` - Генерация QR-кодов для тестирования
- `test_qr_data.py` - Тестирование данных QR-кодов

### `/tests` - Тестовые скрипты
Автономные скрипты для тестирования отдельных модулей:

- `test_approve.py` - Тест процесса одобрения заявок
- `test_auth.py` - Тест системы авторизации
- `test_photo_flow.py` - Тест загрузки и обработки фотографий

## 🔧 Использование

**Для продакшена используйте только:**
- `run_bot.py` - основной скрипт запуска бота
- Административные функции через бота (`/admin` команды)

**Если вам нужна функциональность из deprecated скриптов:**
1. Проверьте совместимость с текущей версией БД
2. Тестируйте только на копии БД
3. Рассмотрите возможность интеграции в основной код

## 📝 История

Эти скрипты были перемещены в `_deprecated/` в рамках подготовки проекта к продакшену (январь 2025).
Оригинальная дата создания файлов: ноябрь 2024 - январь 2025.

## ⚡ Восстановление

Если вам нужно восстановить какой-либо скрипт в основной код:

```powershell
# Пример
Move-Item _deprecated\admin\create_admin.py .
```

**Перед восстановлением:**
- Убедитесь, что скрипт необходим
- Проверьте совместимость
- Обновите документацию
