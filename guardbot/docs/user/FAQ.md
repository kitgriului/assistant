# ❓ FAQ и Руководство пользователя GuardBot

## 🤔 Часто задаваемые вопросы

### Общие вопросы

**Q: Что такое GuardBot?**
A: GuardBot - это Telegram-бот для автоматизации системы пропусков и заявок с использованием QR-кодов.

**Q: Кто может использовать бота?**
A: Бот предназначен для трех типов пользователей:
- Заявители (подают заявки на пропуск)
- Администраторы/Охранники (одобряют заявки)
- Клиенты (просматривают отчеты)

**Q: Какие документы нужны для заявки?**
A: Необходимо фото документа удостоверяющего личность (паспорт, ID карта).

### Технические вопросы

**Q: Почему бот не отвечает на команды?**
A: Возможные причины:
1. Бот не запущен
2. Конфликт соединений (несколько экземпляров)
3. Неправильный токен
4. Проблемы с сетью

**Q: Что означает ошибка "Token is invalid"?**
A: Токен бота неверный или устарел. Получите новый токен у @BotFather.

**Q: Почему не генерируется QR код при approve?**
A: Частые причины:
1. Заявка уже одобрена (статус "approved")
2. Заявка с указанным ID не существует
3. Ошибка в команде (используйте `/approve 2`, а не `/approve <2>`)

**Q: Как проверить статус заявок?**
A: Используйте команду `/list_requests` для просмотра всех заявок и их статусов.

## 📖 Руководство пользователя

### Для заявителей

#### Подача заявки на пропуск

1. **Начните диалог с ботом**
   ```
   /start
   ```

2. **Подайте заявку**
   ```
   /request
   ```

3. **Заполните данные пошагово:**
   - **ФИО**: Введите полное имя
   - **Цель визита**: Опишите причину посещения
   - **Дата/время**: Укажите в формате "YYYY-MM-DD HH:MM"
   - **Фото документа**: Отправьте четкое фото паспорта/ID

4. **Получите QR код**
   - Бот автоматически сгенерирует QR код
   - Сохраните QR код для прохода

#### Пример заполнения:
```
Бот: "Please send your full name (ФИО):"
Вы: "Иванов Иван Иванович"

Бот: "Purpose of visit:"
Вы: "Деловая встреча с отделом продаж"

Бот: "Date and time (e.g. 2025-10-22 14:30):"
Вы: "2025-10-23 15:00"

Бот: "Please send a photo of your document (ID/passport):"
Вы: [отправляете фото паспорта]

Бот: [отправляет QR код] "Ваш QR-код. ID заявки: 5"
```

### Для администраторов/охранников

#### Одобрение заявок

1. **Получите ID заявки**
   - Из уведомления системы
   - Или через `/list_requests`

2. **Одобрите заявку**
   ```
   /approve 123
   ```
   Где 123 - ID заявки

3. **Получите QR код**
   - Бот отправит QR код для прохода
   - QR код можно передать заявителю

#### Патрулирование

1. **Начните патруль**
   ```
   /patrol
   ```

2. **Отправьте местоположение или QR код**
   - Текстом: "Checkpoint 1"
   - Координатами: "55.7558, 37.6176"
   - QR кодом: "request:123"

3. **Отправьте фото для фиксации**
   - Фото места патрулирования
   - Фото инцидента (если есть)

### Для клиентов

#### Просмотр заявок

```
/list_requests
```

Ответ:
```
Requests:
1: Иванов И.И. - approved
2: Петров П.П. - pending
3: Сидоров С.С. - approved
```

#### Экспорт данных

```
/export_requests
```

Бот отправит файл с данными всех заявок.

## 🔧 Диагностика проблем

### Проблема: Команда не выполняется

**Симптомы:**
- Бот не отвечает на команды
- Получаете "echo: /approve 1"

**Решение:**
1. Проверьте правильность команды
2. Убедитесь что бот запущен
3. Проверьте логи: `tail -f guardbot.log`

### Проблема: Заявка не найдена

**Симптомы:**
```
Заявка с id=999 не найдена.
```

**Решение:**
1. Проверьте существующие заявки: `/list_requests`
2. Используйте правильный ID
3. Убедитесь что заявка создана

### Проблема: QR код не генерируется

**Симптомы:**
```
⚠️ Заявка уже одобрена.
```

**Решение:**
1. Проверьте статус заявки
2. Используйте заявку со статусом "pending"
3. Создайте новую тестовую заявку

### Проблема: Фото не загружается

**Симптомы:**
- Ошибка при отправке фото
- "Пожалуйста, отправьте фото документа"

**Решение:**
1. Отправьте фото как изображение (не файл)
2. Убедитесь что фото не превышает 20MB
3. Используйте форматы: JPG, PNG

## 📊 Статистика и мониторинг

### Просмотр статистики заявок

```sql
-- Подключение к SQLite
sqlite3 guardbot.db

-- Общее количество заявок
SELECT COUNT(*) FROM requests;

-- Заявки по статусам
SELECT status, COUNT(*) FROM requests GROUP BY status;

-- Заявки за последние 7 дней
SELECT * FROM requests WHERE datetime > date('now', '-7 days');
```

## 🔐 Безопасность

### Рекомендации по безопасности

1. **Токен бота**
   - Никогда не публикуйте токен
   - Регулярно обновляйте токен
   - Используйте переменные окружения

2. **Доступ к боту**
   - Ограничьте список администраторов
   - Ведите лог всех операций
   - Проверяйте права доступа

3. **Данные**
   - Регулярно создавайте бэкапы
   - Шифруйте чувствительные данные
   - Удаляйте старые медиафайлы
