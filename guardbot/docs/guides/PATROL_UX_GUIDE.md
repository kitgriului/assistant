# Руководство по модулю "Управление обходами" v2.0

## 📱 Для пользователей (охранники)

### Как начать обход

1. **Откройте меню:**
   - В главном меню выберите "🛡️ Управление обходами"

2. **Если нет активного обхода:**
   ```
   🛡️ Управление обходами
   
   Нет активного обхода.
   Начните новый обход или посмотрите архив завершённых.
   
   [🚶 Начать новый обход]
   [📂 Архив обходов]
   [↩️ В главное меню]
   ```

3. **Если есть активный обход:**
   ```
   🛡️ Управление обходами
   
   ✅ Есть активный обход
   📅 Начат: 02.11.2025 15:30
   📍 Точек: 5
   
   Выберите действие:
   
   [▶️ Продолжить обход]
   [📊 Статистика]
   [✅ Завершить обход]
   [📂 Архив обходов]
   [↩️ В главное меню]
   ```

---

### Работа с точками обхода

#### Добавление точки

1. Нажмите "➕ Добавить точку обхода"
2. Откроется меню точки:

```
📍 Точка обхода №1

📸 Фотографий: 0
⏹️ Геолокация
⏹️ Заметка

Добавьте данные и завершите точку.

[📸 Фото (0)]  [📍 Геолокация]
[📝 Заметка]
[✅ Завершить точку]
[◀️ Назад в обход]
[❌ Отменить точку]
```

#### Добавление фото

1. Нажмите "📸 Фото (0)"
2. Просто отправьте фото (из галереи или камеры)
3. Можете отправить несколько фото подряд
4. Счётчик обновится: "📸 Фото (2)"

**Совет:** Не нужно нажимать никаких специальных кнопок - просто отправляйте фото!

#### Добавление геолокации

1. Нажмите "📍 Геолокация"
2. Нажмите кнопку "📍 Отправить геолокацию" (появится внизу)
3. После добавления кнопка изменится на "✅ Геолокация"

#### Добавление заметки

1. Нажмите "📝 Заметка"
2. Напишите текст заметки (например: "Все в порядке" или "Обнаружена неисправность")
3. Заметка сохранится автоматически
4. Кнопка изменится на "✅ Заметка"

#### Сохранение и возврат

- **"◀️ Назад в обход"** - сохраняет прогресс точки и возвращает в меню обхода
  - Полезно если нужно что-то проверить в других точках
  - Можно вернуться к этой точке позже

- **"✅ Завершить точку"** - завершает точку окончательно
  - Переходит к следующему номеру точки
  - Точка сохраняется в БД

- **"❌ Отменить точку"** - удаляет точку полностью
  - Все фото/заметки/геолокация удаляются
  - Используйте если точка добавлена по ошибке

## 🎯 Типичные сценарии

### Сценарий 1: Стандартный обход

1. Начать новый обход
2. Добавить точку №1
   - Сделать 2-3 фото
   - Добавить геолокацию
   - Написать заметку "Территория в порядке"
   - Завершить точку
3. Добавить точку №2
   - Аналогично
4. После всех точек - "✅ Завершить обход"

**Результат:** Обход сохранён в архиве со всеми данными.

---

### Сценарий 2: Прерванный обход

1. Начать обход
2. Добавить 3 точки
3. Закрыть бота (по любой причине)
4. Вернуться позже
5. "▶️ Продолжить обход"
6. Добавить оставшиеся точки
7. Завершить обход

**Результат:** Все данные сохранены, обход можно продолжить в любое время.

---

### Сценарий 3: Исправление ошибки

1. Во время добавления точки поняли, что точка не нужна
2. Нажать "❌ Отменить точку"
3. Продолжить обход

**Результат:** Ошибочная точка удалена, нумерация корректна.

---

### Сценарий 4: Просмотр истории

1. "📂 Архив обходов"
2. Навигация по страницам
3. Выбрать интересующий обход: `/patrol_details_15`
4. Посмотреть все детали, фото, заметки

**Результат:** Полная информация о прошлом обходе.

---

## ⚠️ Важные моменты

### ✅ Что можно:

- Начать новый обход только если нет активного
- Продолжить обход после закрытия бота
- Добавить сколько угодно фото к точке
- Вернуться к точке через "◀️ Назад в обход"
- Просматривать архив в любое время
- Добавлять точки с любой комбинацией данных (только фото, только заметка, всё вместе)

### ❌ Что нельзя:

- Иметь 2 активных обхода одновременно
- Редактировать завершённый обход
- Изменить нумерацию точек

### 💡 Советы:

1. **Всегда добавляйте геолокацию** - это подтверждает что вы действительно были на объекте
2. **Пишите краткие заметки** - "Все в порядке" или "Обнаружена проблема: ..."
3. **Делайте 2-3 фото на точку** - разные ракурсы
4. **Завершайте обход после окончания смены** - не оставляйте открытыми

## 🆘 Решение проблем

### Проблема: Нельзя начать новый обход

**Причина:** Есть активный обход  
**Решение:** 
1. Продолжите текущий обход и завершите его
2. ИЛИ попросите администратора завершить обход принудительно

### Проблема: Фото не загружаются

**Причина:** Технические проблемы  
**Решение:**
1. Проверьте интернет-соединение
2. Попробуйте отправить фото меньшего размера
3. Обратитесь к администратору

### Проблема: Не видно старых обходов

**Причина:** Используйте пагинацию  
**Решение:** В архиве используйте кнопки "◀️ Назад" / "Вперёд ▶️"
