# 📋 Процесс подачи заявки на пропуск

## Дизайн процесса

### 1️⃣ Выбор типа пропуска
Пользователь выбирает между:
- 🚶 **Пешеход** - пропуск для физического лица
- 🚗 **Автомобиль** - пропуск для транспортного средства

### 2️⃣ Выбор цели визита

#### Для пешехода:
- 👔 **Деловая встреча**
- 📦 **Получение груза**
- 🚚 **Доставка**
- ✏️ **Другое (указать)** - свободный текстовый ввод

#### Для автомобиля:
- 🚛 **Погрузка/разгрузка**
- 🚚 **Доставка**
- 🚗 **Служебная поездка**
- ✏️ **Другое (указать)** - свободный текстовый ввод

### 3️⃣ Выбор даты
Интерактивный календарь с навигацией по месяцам. Прошедшие даты недоступны.

### 4️⃣ Выбор времени
Выбор времени в интервале 8:00-20:00 с шагом 30 минут.

### 5️⃣ Документы

#### Для пешехода:
- 📷 Фото документа (паспорт, ID)

#### Для автомобиля:
- 🚗 Номер автомобиля (текстовый ввод)
- 📷 Фото тех. паспорта транспортного средства

### 6️⃣ Подтверждение
Система генерирует:
- Уникальный ID заявки
- QR-код для предъявления на КПП
- Показывает сводку по заявке

## Отмена процесса
На любом этапе пользователь может:
- Нажать кнопку **"❌ Отменить"** (в inline-клавиатуре)
- Написать `/cancel` или `отмена` (при текстовом вводе)

## Структура данных

### База данных (таблица `requests`)
```python
- id: int (Primary Key)
- applicant_id: int (Foreign Key -> users.id)
- name: str (ФИО заявителя)
- pass_type: str ("pedestrian" | "vehicle")
- purpose: str (цель визита)
- datetime: str (дата и время визита)
- photo: str (путь к файлу)
- car_number: str | None (номер авто, только для vehicle)
- status: str ("pending" | "approved" | "rejected" | "used" | "expired")
- qr_code: str (уникальный код)
- created_at: datetime
- processed_by_id: int | None (кто обработал)
- processed_at: datetime | None
- rejection_reason: str | None
```

### FSM States
```python
ApplicantStates.pass_type       # Выбор типа пропуска
ApplicantStates.purpose         # Выбор цели (inline buttons)
ApplicantStates.custom_purpose  # Ввод своей цели (text input)
ApplicantStates.photo           # Загрузка фото
ApplicantStates.car_number      # Ввод номера авто (только для vehicle)
```

## Callback Data Format

### Тип пропуска
- `passtype_pedestrian` - выбран пешеход
- `passtype_vehicle` - выбран автомобиль

### Цель визита
- `purpose_meeting` - деловая встреча
- `purpose_pickup` - получение груза
- `purpose_delivery` - доставка
- `purpose_loading` - погрузка/разгрузка
- `purpose_business` - служебная поездка
- `purpose_custom` - другое (требует ввода)

### Календарь
- `cal_ignore` - неактивная дата
- `cal_prev_{year}_{month}` - предыдущий месяц
- `cal_next_{year}_{month}` - следующий месяц
- `cal_day_{year}_{month}_{day}` - выбор даты

### Время
- `time_{hour}_{minute}` - выбор времени (например, `time_09_30`)

### Навигация
- `cancel_request` - отмена создания заявки
- `main_menu` - возврат в главное меню
- `menu_pending` - переход к заявкам
