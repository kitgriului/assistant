- [ ] **День 3-4**: Автоистечение пропусков

- [ ] **День 5**: История использования

  - [ ] Middleware для перехвата исключений
  - [ ] Try/except во всех handlers
  - [ ] Логирование ошибок в файл

- [ ] **День 8-9**: Валидация данных
  - [ ] Pydantic модели для input
  - [ ] Проверка формата номера авто
  - [ ] Санитизация текстовых полей

- [ ] **День 10**: Тестирование и фиксы
  - [ ] Написать unit-тесты
  - [ ] Integration тесты
