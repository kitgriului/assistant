## 🗄️ База данных

### Структура (актуальная)

**users**
- id, telegram_id (unique), phone_number (unique)
- name, role (admin/guard/guest), is_blocked
- registered_at, last_activity

**requests**
- id, applicant_id (FK → users.id)
- name, pass_type (pedestrian/vehicle), purpose
- datetime, photo, car_number (nullable)
- status (pending/approved/rejected/used/expired)
- qr_code (UUID), created_at
- processed_by_id (FK), processed_at, rejection_reason
- valid_until (nullable)

**patrols** (не используется)
- id, timestamp, code, photo

**patrol_events** (не используется)
- id, guard_id, started_at, completed_at, status

## ⚠️ Известные проблемы

1. **ServerDisconnectedError** - периодически, переподключение автоматическое
2. **Нет уведомлений заявителям** - QR не отправляется автоматически
3. **Пропуска не истекают** - нет cronjob для проверки
4. **Нет истории использования** - неизвестно, использован ли пропуск
5. **Фото не удаляются** - накапливаются в data/media/
6. **Нет тестов** - изменения могут сломать функционал
