## 📝 Инструкция для тестирования

### Шаг 1: Остановите конфликтующий бот
```bash
# Вариант 1: Через BotFather
# Отправьте /setwebhook в BotFather
# Установите пустой webhook

# Вариант 2: Найдите процесс
Get-Process python | Stop-Process
```

### Шаг 2: Инициализируйте пользователей
```bash
.\.venv\bin\python init_users.py init
```

Будут созданы:
- **admin** / admin123
- **guard1** / guard123
- **guard2** / guard123

### Шаг 3: Запустите бота
```bash
.\.venv\bin\python run_bot.py
```

### Шаг 4: Тестируйте в Telegram

#### Тест 1: Регистрация гостя
1. Отправьте `/start` боту
2. Введите ФИО
3. Проверьте, что получили приветствие с командами гостя

#### Тест 2: Подача заявки
1. Отправьте `/request`
2. Заполните данные (ФИО, цель, дата, фото)
3. Проверьте получение QR-кода

#### Тест 3: Логин охранника
1. Используйте другой Telegram аккаунт
2. Отправьте `/start`
3. Введите логин: `guard1`
4. Введите пароль: `guard123`
5. Проверьте список команд охранника
