Перед тестированием необходимо:

1. **Установить Python 3.8+** (если не установлен)
2. **Установить зависимости:**

## 📝 Пошаговое тестирование

### Шаг 1: Подготовка

1. Убедитесь, что в корневой директории есть файл `.env`:
   ```env
   BOT_TOKEN=your_telegram_bot_token
   DB_URL=sqlite+aiosqlite:///./guardbot.db
   ```

2. Если у вас проблемы с установкой bcrypt, можно использовать временную версию (уже применено в `utils/auth.py`)

### Шаг 2: Инициализация пользователей

#### Вариант B: Через тестовый скрипт

Это создаст тестовых пользователей и проверит систему аутентификации.

#### Вариант C: Вручную через Python
```python
import asyncio
from database.session import get_session, engine
from database.models import Base, User
from utils.auth import hash_password

async def create_users():
    # Создаём таблицы
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
    
    # Создаём админа
    async with get_session() as session:
        admin = User(
            telegram_id=0,
            login="admin",
            password_hash=hash_password("admin123"),
            name="Администратор",
            role="admin",
            is_authenticated=False
        )
        session.add(admin)
        await session.commit()
        print("✅ Создан администратор: admin / admin123")

asyncio.run(create_users())
```

### Шаг 4: Тестирование сценариев

#### Сценарий 1: Регистрация гостя ✅

1. Откройте Telegram, найдите вашего бота
2. Отправьте `/start`
3. **Ожидаемый результат:**
   - Бот попросит ввести ФИО
4. Введите ваше ФИО (например: "Иван Иванов")
5. **Ожидаемый результат:**
   - Сообщение: "✅ Регистрация завершена!"
   - Список команд для гостя
6. Отправьте `/request`
7. **Ожидаемый результат:**
   - Начнётся процесс подачи заявки

#### Сценарий 2: Логин охранника ✅

1. Откройте Telegram от имени другого пользователя (или удалите БД)
2. Отправьте `/start`
3. **Ожидаемый результат:**
   - Если вы новый пользователь, бот попросит ФИО
   - Введите ФИО
4. Для логина как охранник нужно, чтобы ваш telegram_id был в БД с ролью guard
5. После регистрации с ролью guard:
   - Отправьте `/start`
   - Введите логин: `guard1`
   - Введите пароль: `guard123`
6. **Ожидаемый результат:**
   - "✅ Авторизация успешна!"
   - Список команд для охранника

#### Сценарий 3: Логин администратора ✅

1. То же что и для охранника, но:
   - Логин: `admin`
   - Пароль: `admin123`
2. **Ожидаемый результат:**
   - Список команд для администратора

#### Сценарий 4: Подача заявки гостем ✅

1. Авторизуйтесь как гость
2. Отправьте `/request`
3. Введите ФИО: "Тест Тестов"
4. Введите цель: "Деловая встреча"
5. Введите дату: "2025-11-05 14:00"
6. Отправьте фото документа
7. **Ожидаемый результат:**
   - Получите QR-код
   - Сообщение с ID заявки
   - Статус: "Ожидает утверждения"

## 🔍 Проверка данных в БД

### Вариант A: Через Python
```python
import asyncio
from sqlalchemy import select
from database.session import get_session
from database.models import User, Request

async def check_db():
    async with get_session() as session:
        # Пользователи
        users = await session.execute(select(User))
        print("👥 Пользователи:")
        for user in users.scalars():
            print(f"  - {user.name} ({user.role})")
        
        # Заявки
        requests = await session.execute(select(Request))
        print("\n📋 Заявки:")
        for req in requests.scalars():
            print(f"  - ID: {req.id}, Статус: {req.status}")

asyncio.run(check_db())
```

## 🐛 Возможные проблемы

### Проблема: "ImportError: No module named 'bcrypt'"
**Решение:** Используется временная версия без bcrypt (уже применена)

### Проблема: "BOT_TOKEN not found"
**Решение:** Создайте файл `.env` с токеном бота

### Проблема: "python не распознано"
**Решение:** 
- Установите Python с python.org
- Или используйте `python.exe` или `py`
- Добавьте Python в PATH

### Проблема: Бот не отвечает
**Решение:**
- Проверьте токен в `.env`
- Убедитесь, что нет других запущенных экземпляров
- Проверьте логи в консоли

### Проблема: "Table doesn't exist"
**Решение:** 
- Удалите `guardbot.db`
- Запустите `python test_auth.py` для создания таблиц
- Или запустите бота - таблицы создадутся автоматически
