# 🚶 Руководство по функционалу обхода территории

## 📋 Описание
Функционал обхода позволяет охранникам фиксировать обход территории, добавляя контрольные точки с фотографиями и геолокацией.

## 🎯 Возможности

### Для охранников:
- ✅ Начать новый обход
- ✅ Добавить произвольное количество точек
- ✅ На каждой точке:
  - 📸 Сделать несколько фотографий (только с камеры!)
  - 📍 Отправить геолокацию
  - 📝 Добавить текстовую заметку
- ✅ Просмотр статистики обхода
- ✅ Продолжение незавершенного обхода
- ✅ Завершение обхода

## 🔒 Безопасность
**ВАЖНО**: Система принимает **только фотографии с камеры**!
- ❌ Нельзя прикрепить файл из галереи
- ❌ Нельзя отправить вчерашнее фото
- ✅ Только съемка в реальном времени через кнопку "📷 Сделать фото"

## 📱 Как использовать

### Начало обхода
1. Войти в бот как охранник
2. Нажать кнопку **"🚶 Новый обход"**
3. Если есть активный обход - выбрать:
   - ▶️ Продолжить текущий
   - ❌ Завершить и начать новый

### Добавление точки
1. В меню обхода нажать **"📍 Добавить точку обхода"**
2. Добавить фото и/или геолокацию:
   - **Фото**: Нажать "📸 Добавить фото" → Использовать кнопку "📷 Сделать фото"
   - **Геолокация**: Нажать "📍 Добавить геолокацию" → "📍 Отправить геолокацию"
   - **Заметка** (опционально): Нажать "📝 Добавить заметку" → Ввести текст
3. Можно добавить несколько фото на одну точку
4. Нажать **"✅ Завершить точку"**

### Завершение обхода
1. В меню обхода нажать **"✅ Завершить обход"**
2. Система покажет статистику:
   - ⏱ Длительность обхода
   - 📍 Количество точек
   - 📸 Количество фотографий

## 📊 Структура данных

### PatrolEvent (Событие обхода)
- ID обхода
- ID охранника
- Время начала/завершения
- Статус (in_progress/completed/cancelled)
- Список точек обхода

### PatrolCheckpoint (Точка обхода)
- Номер точки
- Время отметки
- Координаты (широта/долгота)
- Заметки
- Список фотографий

### CheckpointPhoto (Фотография)
- Путь к файлу
- Время загрузки
- Описание

## 🗄️ База данных
Данные сохраняются в таблицах:
- `patrol_events` - события обхода
- `patrol_checkpoints` - контрольные точки
- `checkpoint_photos` - фотографии на точках

## 💡 Примеры использования

### Обход территории
```
1. Охранник нажимает "Новый обход"
2. Точка №1: Главный вход
   - Фото 1: Общий вид
   - Фото 2: Замок на воротах

   - Заметка: "Замок в порядке"

   - Геолокация: 55.751100, 37.618500

```

```
1. Точка: Склад №3
   - Фото 1-3: Общий вид помещения
   - Фото 4: Показания датчика температуры
   - Заметка: "Температура +18°C, норма"
   - Геолокация
```

## ❓ Частые вопросы

**В: Можно ли добавить фото из галереи?**  
О: Нет, только съемка в реальном времени через камеру.

**В: Сколько точек можно добавить?**  
О: Неограниченно.

**В: Сколько фото на одну точку?**  
О: Неограниченно.

**В: Обязательно ли добавлять геолокацию?**  
О: Нет, но желательно. Минимум - одно фото или геолокация.

**В: Можно ли удалить точку?**  
О: Да, до завершения точки можно нажать "❌ Отменить точку".

**В: Можно ли продолжить обход на следующий день?**  
О: Да, обход остается активным до завершения.

## 🛠️ Техническая информация

### FSM состояния
- `in_patrol` - обход активен
- `waiting_checkpoint_action` - ожидание действия на точке
- `waiting_photo` - ожидание фото
- `waiting_location` - ожидание геолокации
- `waiting_notes` - ожидание заметок

### Обработчики
- `handlers/patrol.py` - весь функционал обхода
- `states/guard.py` - FSM состояния
- `database/models.py` - модели БД
